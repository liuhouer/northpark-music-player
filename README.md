**NorthPark Music Player**

基于 Electron 的本地音乐播放器，专注流畅体验与现代化交互。

### 核心特性
- **现代化界面**：深色紫罗兰主题 + 网格布局，左侧边栏导航与歌单管理，底部播放栏 + 歌曲列表表格
- **强大播放能力**：支持虚拟滚动（千首级歌单流畅渲染）、Fisher-Yates 随机播放（可精准回溯上一曲/下一曲）、循环模式徽章显示
- **桌面歌词**：自定义颜色、字体大小、锁定状态；锁定后智能鼠标穿透（歌词区域完全穿透，控制栏保留交互）
- **导入与元数据**：多文件选择/拖拽导入、实时统计面板、ID3 标签查看与编辑（MP3）、支持 MP3 / FLAC / WAV / AAC / OGG / M4A
- **系统集成**：文件关联、双击音频文件直接打开、设为默认播放器、定位当前歌曲
- **其他亮点**：音乐频谱可视化、搜索防抖、拖拽排序、歌单上下文传递、XSS 防护（HTML 转义）

### 性能表现
- 千首级歌单内存占用 ≤ 300 MB，空闲 CPU < 1%
- 歌单切换、搜索过滤、播放状态更新等高频操作无卡顿
- 元数据按需分批加载 + skipCovers，显著降低开销

### 快速开始
```bash
npm install
npm start          # 本地运行
npm run dist       # 打包成 App
```

图标要求：256×256 ICO，大小 ≤ 50 KB

## v1.1.3 高性能列表渲染与智能随机播放

### 新增
- 引入虚拟滚动技术，千首级歌单流畅渲染，大幅降低内存与 CPU 占用
- 基于 Fisher-Yates 洗牌算法的随机播放队列，支持上一曲 / 下一曲在随机序列中精准回溯
- 搜索输入防抖处理，提升高频输入场景下的检索响应体验
- 循环播放状态以徽章形式直观呈现，播放模式一目了然
- 输出内容自动 HTML 转义，防范潜在 XSS 安全风险

### 优化
- 重构播放状态更新机制，采用局部 DOM 更新替代全量重绘，UI 响应更迅捷
- 元数据加载策略按需分批执行，仅解析视口可见曲目，配合 `skipCovers` 减少无效开销
- 歌曲定位功能限定于当前歌单作用域，避免误切列表导致上下文丢失

### 性能表现
- 千首级歌单内存占用控制在 300 MB 以内，空闲 CPU 降至 1% 以下
- 歌单切换、搜索过滤与播放状态变更等高频操作无卡顿
