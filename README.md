# northpark-music-player

**本项目使用 Electron 完成了一个本地音乐播放器**

使用本项目

第一步安装依赖

```bash
npm install
```

本地运行项目

```bash
npm start
```

项目打包成 App

```bash
npm run dist
```

```bash
 ico图标256 *256 ;size <=50kb
```

## v1.1.3 高性能列表渲染与智能随机播放

### 新增
- 引入虚拟滚动技术，千首级歌单流畅渲染，大幅降低内存与 CPU 占用
- 基于 Fisher-Yates 洗牌算法的随机播放队列，支持上一曲 / 下一曲在随机序列中精准回溯
- 搜索输入防抖处理，提升高频输入场景下的检索响应体验
- 循环播放状态以徽章形式直观呈现，播放模式一目了然
- 输出内容自动 HTML 转义，防范潜在 XSS 安全风险

### 优化
- 重构播放状态更新机制，采用局部 DOM 更新替代全量重绘，UI 响应更迅捷
- 元数据加载策略按需分批执行，仅解析视口可见曲目，配合 `skipCovers` 减少无效开销
- 歌曲定位功能限定于当前歌单作用域，避免误切列表导致上下文丢失

### 性能表现
- 千首级歌单内存占用控制在 300 MB 以内，空闲 CPU 降至 1% 以下
- 歌单切换、搜索过滤与播放状态变更等高频操作无卡顿
